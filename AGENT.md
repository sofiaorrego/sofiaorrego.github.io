# Guía de trabajo

[AGENTS.md](AGENTS.md) es la guía que Codex carga al abrir este repositorio. Léela antes de programar.

Empieza revisando cambios locales y actualizando `main` con `git pull --ff-only origin main` cuando sea seguro. Escribe primero la prueba, valida el resultado, haz commits pequeños y ejecuta `git push` al destino verificado.

Usa la guía central de este repo para el flujo Git y las pruebas. Para cambiar la UI, revisa primero Impeccable, el índice de Base UI en `components/llms.txt` y el componente TypeScript que corresponda.
